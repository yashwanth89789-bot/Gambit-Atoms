## 🌟 Platform Overview

**Gambit Atoms** unites cutting-edge artificial intelligence, quantum physics, and systems software into a single unified reactive web application. Whether you are profiling a distributed PagedAttention v3 Triton kernel across an 8x NVIDIA H100 cluster, synthesizing a distance-3 Surface Code quantum circuit at 12.4 mK, or autonomously authoring and double-blind peer-reviewing an academic preprint with verified numerical parity proofs, Gambit Atoms provides the tools to build, simulate, and verify.

### 🔑 Key Engineering Highlights
- **Sub-Millisecond Inference Profiling**: Interactive benchmarks comparing baseline HuggingFace, vLLM, TensorRT-LLM, and Gambit Atoms PagedAttention kernels.
- **Transmon Qubit Fidelity Simulation**: Real-time 3D Bloch sphere rendering with arbitrary angle rotations, decoherence relaxation ($T_1, T_2^*$), and BB84 quantum cryptography.
- **Neuro-Symbolic Cognitive OS**: Graph-based memory topology combining Tree-of-Thought (ToT) search, entropy attention heatmaps, and working-memory vector pools.
- **Sandboxed Python / CUDA Environment**: Monaco-powered code editor with simulated PyTorch 2.6 execution, VRAM telemetry, and real-time execution logs.
- **Autonomous Open-Source Pull Requests**: Generate high-performance CUDA diffs, benchmark speedup tables, and zero-day CVE patches for upstream GitHub repositories.

## ⚡ Core Operational Modules

### 1. Cognitive Core (APEX Cognitive OS)
The cognitive brain of Gambit Atoms. Employs neuro-symbolic reasoning to orchestrate complex problem decomposition.
- **Symbolic Knowledge Graph**: Real-time graph network mapping semantic relations, entity nodes, and activation levels.
- **Tree-of-Thought (ToT) Planner**: Explores parallel reasoning branches using Monte Carlo rollout evaluation and state backtracking.
- **Attention Heatmap Matrix**: Live inspection of query-key attention distribution and Shannon entropy values.
- **Cognitive Topology Canvas**: Interactive force-directed canvas displaying cluster activations and associative pathways.
- **Persistent Cognitive Store**: Multi-tier memory spanning Working Memory, Episodic Logs, Semantic Triples, and Long-Term Vector Embeddings.

### 2. Autonomous Assistant Creator
Architect and deploy specialized AI agents powered by the Google Gemini API.
- **6 Domain Archetypes**: *Deep Researcher*, *Code Architect*, *Theorem Prover*, *Systems SRE*, *Quantum Physicist*, and *Security Auditor*.
- **Cognitive Sliders**: Calibrate Temperature, Reasoning Depth, Hallucination Penalty, and Tool Execution Autonomy.
- **Tool Matrix Integration**: Toggle access to Python REPL, Shell execution, ArXiv search, Vector database lookup, and Git operations.
- **Execution Sandbox**: Real-time agent chat simulator with step-by-step chain-of-thought traces and token velocity counters.
- **Multi-Format Export Hub**: 1-click export to Docker container Dockerfiles, asynchronous Python SDK scripts, LangChain agents, or OpenAPI specifications.

### 3. Quantum Computing & QPU Laboratory
A full physical quantum hardware simulation operating at millikelvin dilution refrigerator temperatures.
- **Interactive Bloch Sphere**: Rotate the qubit state vector across azimuthal ($\phi$) and polar ($\theta$) angles. Apply single-qubit gates ($X, Y, Z, H, S, T$) and observe instantaneous state probabilities.
- **Cryogenic Hardware Profiler**: Inspect dilution refrigerator stages ($50\text{ K} \to 4\text{ K} \to 0.8\text{ K} \to 12.4\text{ mK}$), microwave coaxial line attenuation, and Purcell filter fidelity.
- **QKD Protocol Simulator (BB84)**: Simulate quantum key distribution between Alice and Bob with configurable eavesdropping detection (Eve interception rate vs. quantum bit error rate QBER).
- **Quantum Annealer Lab**: Formulate combinatorial optimization problems as Quadratic Unconstrained Binary Optimization (QUBO) matrices and compute ground-state spin configurations.
- **Surface-17 QEC (Quantum Error Correction)**: Simulate topological surface codes with 9 data qubits and 8 syndrome ancillas to detect and correct bit-flip ($X$) and phase-flip ($Z$) errors.

### 4. Research Lab & Peer Review Engine
Automated scientific publishing pipeline upholding rigorous academic standards.
- **Autonomous Paper Generator**: Compiles complete research preprints formatted with LaTeX typesetting, mathematical proofs, and quantitative benchmark tables.
- **Double-Blind Peer Reviewer**: Evaluates submitted papers across 5 quantitative dimensions: *Originality*, *Methodological Soundness*, *Empirical Rigor*, *Reproducibility*, and *Clarity*.
- **Numerical Parity Verification**: Runs automated checks ensuring float64 mathematical parity against reference implementations.
- **Multi-Format Citation Generator**: Generates formatted citations in BibTeX, IEEE, APA, MLA, and Chicago styles.

### 5. Platform Architecture Designer
High-throughput systems architect for distributed machine learning clusters.
- **Vision-Language-Action (VLA) Pipeline**: Interactive tokenizer mapping 120 FPS multi-camera sensor feeds to continuous joint actions at 250 Hz.
- **Tensor Sharding Profiler**: Configure 4D parallelism strategies (Tensor Parallelism $TP$, Pipeline Parallelism $PP$, Data Parallelism $DP$, Expert Parallelism $EP$) with automatic communication overhead calculation.
- **RLAIF Policy Alignment**: Verify invariant safety rules and reward model calibration before deployment.
- **Infrastructure-as-Code (IaC)**: Generates production Kubernetes Helm values, Slurm batch scripts, and Ray cluster manifests.

### 6. Collaborative IDE Workspace & Sandbox
Professional developer environment built on Microsoft Monaco Editor.
- **Live Monaco Studio**: Full TypeScript, Python, CUDA, and JSON editing with minimap, syntax diagnostics, and hotkey support.
- **Container Execution Sandbox**: Run code in simulated PyTorch 2.6 / CUDA 12.8 runtime with standard out, error streams, memory usage meters, and exit codes.
- **Neural AI Copilot**: Instant code refactoring, kernel speedup estimation, and static bug detection.
- **Algorithm Library**: Pre-loaded with FlashAttention-3 kernels, Ring AllReduce routines, BB84 cryptography scripts, and Monte Carlo tree search algorithms.

### 7. Global Scale Ops Solver
Mission-control telemetry for distributed GPU clusters and inference infrastructure.
- **InfiniBand & NVLink Telemetry**: Monitor 900 GB/s inter-GPU interconnect bandwidth, RoCEv2 packet loss, and PCIe Gen5 throughput.
- **KV-Cache Memory Hierarchies**: Track tiered cache allocation between on-chip SRAM, HBM3e, Host DDR5 RAM, and NVMe-oF pools.
- **Byzantine Quorum & Auto-Failover**: Automated health checks triggering sub-second worker node failover without losing generation state.

### 8. Open Source AI Contributor & README Studio
Automate and streamline contributions to the world's most critical open-source AI repositories.
- **Automated PR Generator**: Synthesize pull requests with production code diffs, benchmark metrics, and speedup reports for `vLLM`, `HuggingFace Transformers`, `OpenAI Triton`, and `DeepSeek`.
- **Zero-Day CVE Audit**: Scan packages for memory safety vulnerabilities and synthesize verified patches.
- **Interactive README.md Studio**:
  - Live GitHub-styled rendered document preview with clickable task lists (`- [x]`).
  - One-click **▶ Run in Sandbox** on code snippets.
  - Visual **Interactive Designer** to customize badges, features, benchmark tables, and BibTeX citations without writing raw markdown.
  - One-click export to clipboard or `.md` file for GitHub repository publication.

### 9. Adaptive Theme & Density Engine
- **7 Color Palettes**: *Midnight Lab*, *Matrix Cyberpunk*, *Obsidian Glass*, *Monokai Pro*, *Cobalt Deep*, *Emerald Science*, and *Solar Amber*.
- **3 Density Modes**: *Compact* (dense data tables), *Default*, and *Relaxed* (reading view).
- **Auto-Adaptive Focus**: The theme palette automatically morphs to match the cognitive context of the active module.

## 🚀 Quickstart & Installation

Follow these steps to run Gambit Atoms on your local machine or server.

### Prerequisites
- **Node.js**: Version `20.0.0` or higher (Node 22 recommended)
- **npm** or **bun**: npm `10.0+` or bun `1.1+`
- **Google Gemini API Key**: Obtain a free or paid key from [Google AI Studio](https://aistudio.google.com/)

### Step 1: Clone the Repository
```bash
git clone https://github.com/gambit-atoms/gambit-atoms.git
cd gambit-atoms
```

### Step 2: Install Dependencies
```bash
npm install
```

### Step 3: Configure Environment Variables
Copy the example environment template:
```bash
cp .env.example .env
```

Open `.env` in your text editor and add your API credentials:
```env
# Google Gemini API Key for autonomous reasoning and agent creation
VITE_GEMINI_API_KEY=your_gemini_api_key_here

# Optional: GitHub credentials for live upstream pull request syncing
GITHUB_TOKEN=your_personal_access_token_here
```

### Step 4: Launch the Development Server
```bash
npm run dev
```

The application will start on **`http://localhost:3000`**. Open your browser to access the complete Gambit Atoms interface.

## 💻 Usage Examples

### 1. Initializing an APEX Cognitive Session
```typescript
import { ApexCognitiveOS } from './src/services/cognitiveService';

const os = new ApexCognitiveOS({
  reasoningDepth: 5,
  entropyThreshold: 0.28,
  treeOfThoughtBranches: 3,
});

const plan = await os.planTask(
  "Optimize flash-decoding kernel for non-contiguous KV-cache memory layout"
);

console.log(`Explored ${plan.exploredBranches} branches. Selected path confidence: ${(plan.confidence * 100).toFixed(1)}%`);
```

### 2. Simulating a Transmon Qubit Rotation & Readout
```typescript
import { TransmonQPU } from './src/services/quantumSimulation';

const qpu = new TransmonQPU({ temperatureMk: 12.4, t1RelaxationUs: 85.0 });

// Apply Hadamard gate followed by Pauli-Z phase rotation
const qubitState = qpu.applyGate('H', 0).applyGate('Z', 0).measure();

console.log(`Qubit 0 outcome: |${qubitState.measuredBit}⟩ (P(|0⟩) = ${qubitState.prob0.toFixed(3)})`);
```

### 3. PagedAttention v3 Batch Inference
```python
import torch
from gambit_atoms import LLMServer, EngineConfig

# Initialize 8-GPU tensor parallel engine
config = EngineConfig(
    model="deepseek-ai/DeepSeek-V3",
    tensor_parallel_size=8,
    kv_cache_utilization=0.94,
    enable_chunked_paged_attention=True
)

server = LLMServer(config)
output = server.generate("Derive the metric tensor for a rotating Kerr black hole:")
print(f"Tokens/sec: {output.metrics.tokens_per_second:.1f}")
```

## 🛠️ Available Scripts

In the project root, you can execute:

| Command | Description |
| :--- | :--- |
| `npm run dev` | Starts the Express backend server with Vite middlewares on port 3000 with hot reload. |
